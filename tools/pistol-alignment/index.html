Real idle animation C5 sampled at frames 0–29. The full 20-joint body pose is decoded, but cosmetic GEO_ASM effects and game/rendering parity are not yet validated. The preview uses translate → scale 2.25 → rotate ZXY, matching intended geo transform order. Animated joints follow the source XYZ matrix convention (Three.js ZYX Euler equivalent) and geolayout offsets (shoulder 68,-10,-79; forearm +65 X; hand +60 X); neutral joint angles are only a pose approximation. The 600-case browser test compares real Three.js world matrices with an independent SM64 formula; it does not validate GPU rendering, mesh alignment, or emulator output. The inverse round-trip checks coordinate inversion. Rendering parity with the game still requires one emulator validation. Do not treat this preview as verified animation or hand-scaler fidelity.
